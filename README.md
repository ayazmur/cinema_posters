# Киноафиша — студия афиш

Настольное приложение для кинотеатра: библиотека фильмов, расписание на неделю
с несколькими сеансами каждого фильма и генерация красивых афиш в нескольких
стилях и форматах. Данные хранятся локально, интернет не нужен.

## Возможности

- **Библиотека фильмов**: название, возраст, формат (2D/3D/IMAX), длительность,
  цена, отметка «Пушкинская карта».
- **Постеры**: выбор файла или **перетаскивание (Drag&Drop)** картинки прямо на
  карточку фильма или на строку в библиотеке.
- **Расписание на неделю**: таблица сеансов, у каждого фильма может быть
  **несколько сеансов** (время, зал, цена, ПК). Быстрое добавление пачкой:
  `10:00, 12:30, 15:00`.
- **8 стилей афиши** и **5 форматов**: соцсеть 16:9, пост 4:5, квадрат,
  Stories 9:16, печать A4.
- **Кнопка «Скопировать расписание»** — текст для публикации в соцсетях.
- **Экспорт PNG** и копирование готовой афиши в буфер обмена.
- **Проекты по неделям**: каждое расписание сохраняется отдельным файлом
  `projects/02.10-08.10.json`, автосохранение при изменениях.
- **Настройки кинотеатра**: название, слоган, логотип, цвета, контакты, залы.
- Тёмный современный интерфейс.

## Установка и запуск

Нужен Python 3.12+.

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

На Linux/macOS:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Или просто запустите `run.bat` (Windows).

## Как пользоваться

1. Добавьте фильмы в **библиотеку** и заполните карточку (название, цена, ПК).
2. Перетащите постер на область предпросмотра или на строку фильма.
3. Выберите фильм и укажите время сеансов — они появятся в таблице. Можно
   добавлять сколько угодно сеансов одному фильму.
4. Выберите **стиль** и **формат** афиши справа — предпросмотр обновится.
5. Нажмите **«Скопировать расписание»** для текста или **«Сохранить PNG»**.
6. Проект сохраняется сам; при смене недели нажмите **«Новая неделя»**.

## Стили афиш

`Классика`, `Сетка постеров`, `Журнальный`, `Неон`, `Минимализм`, `Ретро`,
`Список`, `Яркие блоки`. Форматы: 1600×900, 1080×1350, 1080×1080, 1080×1920,
2480×3508.

## Структура

```
app.py                  точка входа
cinema/
  models.py             фильмы, сеансы, настройки, проект
  storage.py            чтение/запись JSON, импорт постеров
  poster.py             генерация афиш (темы и форматы)
  schedule_text.py      текст расписания для публикации
  widgets.py            Drag&Drop-виджеты
  settings_dialog.py    настройки кинотеатра
  main_window.py        главное окно
  ui_theme.py           оформление интерфейса
assets/                 встроенные ресурсы (шрифты, .gitkeep)
data/movies.json        библиотека фильмов
data/settings.json      настройки кинотеатра
projects/               недельные проекты (*.json)
posters/                загруженные постеры
output/                 готовые афиши
```

## Сборка в .exe

Локально:

```bat
build.bat
```

или вручную:

```bash
pip install -r requirements-dev.txt
pyinstaller cinema.spec --noconfirm
```

Результат — `dist\Kinofisha.exe` (один файл, установка не требуется). Данные
сохраняются рядом с `.exe` в папках `data/`, `projects/`, `posters/`, `output/`.

## Автоматический релиз

Workflow `.github/workflows/build.yml` собирает `.exe` при **push в `main` или
`master`** и автоматически публикует его в релиз с тегом `latest`. Скачать
последнюю сборку можно по ссылке
`https://github.com/<user>/<repo>/releases/latest`. Также сборку можно запустить
вручную через `workflow_dispatch`.
